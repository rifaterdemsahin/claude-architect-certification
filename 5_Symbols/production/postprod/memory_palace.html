🏛️ Memory Palace Builder

Turn each module's full script into a method-of-loci memory palace — a themed location whose rooms hold vivid mnemonic images, so the audience can mentally walk the lesson and remember every concept.

🧠 How it works. Pick a module → press Generate Memory Palace. The builder reads every video script in that module, extracts its hooks, objectives, key insights and quiz points, and places each one as a vivid image inside a room of a themed palace. Walk the rooms in order to recall the whole module. Press Save to store the palace for that module in Supabase.

🚶 Method of Loci

An ancient memory technique: attach each idea to a place along a familiar route. Recall the route, recall the ideas — in order.

🎨 Make it vivid

The stranger and more exaggerated the image, the stickier it is. Giant, on fire, talking, out of place — that's the point.

🎬 Use on camera

Narrate the walk in the recap segment, or hand the audience the palace as a downloadable revision aid for the module.
