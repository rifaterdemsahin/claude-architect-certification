🖥️ Screen Recording Guide

⚙️ OBS Settings

  • Canvas: 1920×1080 (scaled from 2560×1440 for sharp text)
  • FPS: 30 (use 60 only for UI animations)
  • Output: Recording → MKV, NVENC H.264, CBR 30Mbps
  • Audio: 48kHz, 320kbps stereo

🖥️ Desktop Prep

  • Close all unrelated apps, tabs, and notifications
  • Set editor font to 16px+ for readability on 1080p
  • Enable "Show mouse clicks" in OBS or macOS Accessibility
  • Use a clean, light-coloured theme (no dark mode for code)

🎬 Framing & Cursor

  • Record the full screen — not a cropped region
  • Cursor size: increase to 150% in system settings
  • Move cursor slowly and deliberately — no frantic motions
  • Pause before clicking so the viewer can follow

🎤 Voiceover

  • Narrate as you go — explain what you are doing before you do it
  • Keep a steady pace — faster than talking head, slower than real typing
  • Pause after each step — makes it easy to insert B-roll or edit
  • Use a separate audio track in OBS for voice (Track 1 = desktop, Track 2 = mic)

📝 Code Recording

  • Zoom editor to 130–150% so code fills the frame
  • Type deliberately — no frantic backspacing
  • Comment as you type — the audience reads slower than you code
  • Highlight key lines with cursor or mouse hover

✂️ Post-Prod Notes

  • Cut long pauses and dead air in post
  • Add arrow callouts or zoom-ins on key UI areas
  • Sync voiceover track to video in DaVinci Resolve
  • Export at 1080p H.264, 20–30Mbps for YouTube
